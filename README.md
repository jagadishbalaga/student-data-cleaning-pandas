# Student Data Cleaning

## Project Overview

This project focuses on cleaning and preparing a student dataset for further data analysis.

### Data Cleaning Steps

* Checked the dataset for missing/null values.
* Converted columns to the appropriate data types.
* Converted numeric columns from string to numeric format where required.
* Handled invalid numeric values using `errors='coerce'`.
* Checked and handled missing values.
* Standardized column names.
* Removed unnecessary spaces and special characters from column names.
* Checked for duplicate records.
* Prepared the cleaned dataset for further analysis.

### Tools Used

* Python
* Pandas
* vs code

### Objective

The main objective of this project is to transform raw student data into a clean and structured dataset that can be used for reliable data analysis and visualization.
